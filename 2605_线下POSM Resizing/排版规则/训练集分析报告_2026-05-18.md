## 1. 测量方法说明

### 参考线
- **成品框 (trim box)**：每张图都有可见的红色细线裁切框，距图边约 2% 图宽。
- **罐心**：以可见罐体顶 (罐盖最高点) 与罐底 (圆柱底缘) 取中点。
- **元素 6 (印章)**：以圆形外圈为 bbox。
- **元素 3 (脚注)**：区分"黑色主行 ink" (\*我们相信…积极作用) 和"fineprint ink bbox"（灰色小字整体）。
- **元素 4 (右下 logo)**：从 5 颗蓝点的上沿到"为每一种未来"汉字的下沿。

### 误差范围
缩略图目测，单位百分比，精度 **±2~3 % 图宽 / 图高**。PNG 像素扫描精度到像素级（误差 < 1%）。

### 主/外样本权重

| 类别 | 图 | 用途 |
|---|---|---|
| **主样本 (高权重)** | 420 / 420安全区 / 425 / 580 | 跨图归纳，4 张近似竖版 (W/H ≈ 0.74) |
| **半外样本 (中权重)** | 885×1480 | 同为窄竖版 (W/H ≈ 0.60) |
| **外样本 (低权重)** | 330×558 / 960×1110 | 极端比例 (窄竖 0.59 / 近方 0.86)，仅做对照 |

## 4. 问题 2：底部组 (元素 3+4) — 最终规则

> 经多轮迭代（目测归纳 → 代码实现 → 用户视觉验收 → 像素扫描精确化 → 再验收），2026-05-18 22:30 定稿。

### 4.1 元素 4 (右下角 logo) 高度规则

**正确规则**：`h4 = th3 × (432/727) ≈ th3 × 0.594`

- 其中 432/727 = fineprint ink bbox 高度 / 3脚注.png 总高
- fineprint ink 范围：y=[287..719) in 3脚注.png（像素扫描精确值）
- w4 由 h4 和元素 4 PNG 宽高比（1.726）反推：`w4 = h4 × (744/431)`

**推导逻辑（视觉对齐）**：
- 元素 4 整体（蓝点 + "为每一种未来"）的视觉高度 → 对应元素 3 中 fineprint 那一块的高度
- 即"logo 的高度感 = fineprint 的高度感"，两者在底部区域视觉量级匹配

**排除的错误路径**：
- ~~"元素 4 高 = 元素 3 黑字主行高"~~（太小，logo 看不清）
- ~~"元素 4 高 = 元素 3 PNG 总高"~~（太大，logo 压过脚注；且几何反推 w4 超界）
- ~~"蓝点行高 = 黑字行高 × K"~~（设计意图不对）

### 4.2 Group 宽度规则

**正确规则**：Group 总宽 = 标题（元素 2）渲染宽 × `GROUP_TO_TITLE_RATIO`（默认 1.02）

- 训练集目测：底部 group 与标题宽度非常接近，略宽 1-3%
- 不再用固定的 EL3_W_RATIO，改为**从 group 目标宽度反解 el3 宽度**：

```
K = (oh3/ow3) × EL3_FINEPRINT_RATIO × (ow4/oh4)   # tw4/tw3 的固定比例
tw3 = (group_target_w − inner_gap) / (1 + K)
```

- K ≈ 0.170（由 PNG 宽高比和 fineprint 比例共同确定，写死为常量）
- 当 GROUP_TO_TITLE_RATIO = 1.02 时，实际 el3 ≈ 72% W，el4 ≈ 12% W，group ≈ 86% W

### 4.3 Group 水平定位

整组水平居中于成品框（不再各自左/右对齐）：

```
group_x = trim_left + (trim_w − group_w) / 2
```

元素 3 ↔ 元素 4 间距：`INNER_GAP = 2% W`

### 4.4 Group 垂直定位（对称规则）

**正确规则**：底部留白 = 顶部联合 logo 距成品框顶部的留白（上下视觉对称）

```
top_logo_margin = y1 − trim_top      # 元素 1 顶边到成品框顶的像素距离
group_bottom    = trim_bottom − top_logo_margin
```

- 不再贴底（原来 4% 底边距），改为"镜像元素 1 的顶部留白"
- 实测：两张城市图（420×570 / 328×470）视觉效果均通过验收

## 5. 问题 3：元素 1 (顶部联合 logo) 与标题的间距

### 5.1 原因分析

原公式 `gap = title_h / 9 ≈ 11% title_h`，视觉上看约有 2 倍行间距的空隙，**偏远**。

根源：**元素 2 标题 PNG 顶部有 8.8% 的软像素**（装饰渐变，非空白）。

视觉间距 = 公式 gap + PNG 顶部 padding：
- 旧公式：11% + 8.8% ≈ **19.8%** → 约 2 倍行间距（10.4%），视觉太远
- 新公式：2% + 8.8% ≈ **10.8%** → 与标题内部行间距（10.4%）匹配 ✓

### 5.2 已落地参数

`gap_logo_title = title_h / 50`（对应约 2% title_h 公式 gap）

## 7. 工程实现（已落地 `template/element_layout.py`）

### 7.1 排版四步逻辑（最终版）

```
Step 1: 标题 (el2)  — 85% W，水平居中，距成品框顶 13%
Step 2: 顶部 logo (el1) — 标题宽 × 50%，同中轴，gap = title_h / 50
Step 3: 底部 Group (el3 + el4)
          └ 尺寸：tw3 由 group_target 反解；h4 = th3 × 0.594；w4 由比例反推
          └ 水平：整组居中
          └ 垂直：group_bottom = trim_bottom − (y1 − trim_top)
Step 4: 印章 (el6) — 15% W，左缘 3% W，中心 Y = trim_top + can_trim_y × 0.73
```

### 7.2 关键 PNG 常量（硬编码，不随 canvas 变化）

```python
EL3_FINEPRINT_RATIO  = 432 / 727   # fineprint ink bbox / PNG总高 ≈ 0.594
GROUP_TO_TITLE_RATIO = 1.02         # group 总宽 / 标题宽
INNER_GAP_RATIO      = 0.02         # el3↔el4 内间距（占成品框宽）
```

### 7.3 待改进（已知缺陷）

1. **方案 B（印章 Y = 罐顶锚定）**：语义更清晰，跨比例更稳，但需要传 `can_top_y` 和 `can_height`；当前 `get_can_canvas_pos()` 只返回罐心，改造成本高，暂用方案 A（系数 0.73）。
2. **fineprint 换行**：当前 el3 PNG fineprint 宽度 ≈ 72% W，训练集主样本 fineprint 最右沿达 84-94% W（设计师手动断行所致）。代码无法复刻断行，接受偶尔视觉差异。
3. **元素 6 "水平偏左" 反馈**：训练集 7 张全部稳定在 3% W，与当前实现一致；反馈原因未确认，等后续复核。
