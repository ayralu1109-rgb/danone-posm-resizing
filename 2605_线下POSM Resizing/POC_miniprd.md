# PoC 方案：线下 POSM 自动排版合成

> 状态：进行中 · 更新日期：2026-05-18

---

## 1. 背景与目标

线下 POSM 物料（海报、展架、陈列牌）在不同渠道/场地需要输出不同尺寸的版本。当前由人工在设计软件中逐一调整，效率低且易出错。

**PoC 目标：** 验证通过自动化流程完成"背景裁切 + 元素排版 + 合成输出"完整链路，实现一套输入素材 → 批量多尺寸 SVG+assets ZIP。

---

## 2. 技术路线

**结论：采用 SVG 路线**

| 维度 | PNG 路线 | SVG 路线（选用） |
|---|---|---|
| 资源消耗 | 高（2m×2m@200DPI≈ 1.5GB/张） | 极低（XML 文本操作） |
| 原始像素 | 裁切/合成后不可逆 | ✅ PNG 以路径引用保留，零像素损失 |
| 可编辑性 | 差（像素已拍平） | ✅ Illustrator 各图层独立可操作 |
| 成品框 | 像素描边，无法单独编辑 | ✅ 原生矢量 `<rect>`，独立图层 |
| 下游交付 | 直接交印刷厂 | 需在 Illustrator 导出 CMYK（标准印刷工作流） |

## 4. 处理流程

```
Master BG  +  规格表（Excel）  +  元素 PNGs
    ↓
Step 1：读取规格
  openpyxl 解析 Excel → CitySpec（城市名、画布尺寸、成品框尺寸）
    ↓
Step 2：背景裁切 → assets/bg.png
  Template.crop_bg()：内容驱动锚点裁切，见 5.1.1
    ↓
Step 3：成品框定位
  居中对齐：trim_x = (canvas_w − trim_w) / 2
    ↓
Step 4：元素坐标计算 + 复制到 assets/
  Template.compute_layout()：基于成品框尺寸按 5.2 比例规则计算坐标
  shutil.copy()：元素原文件复制至 assets/，不修改像素
    ↓
Step 5：构建 SVG
  xml.etree.ElementTree，viewBox = 画布尺寸（px）
  所有 <image> 和 <rect> 附加 data-*-mm 属性（毫米调试信息）
    ↓
Step 6：打包 ZIP
  {城市}_{尺寸mm}.zip  ←  SVG + assets/
```

**异常处理：** Step 2/4 发生异常时整行跳过，全批次结束后输出异常清单。

## 5. 排版规则

### 5.1 基础规则

- **画布基准**：Excel 画面尺寸（大值）= 画布；可视尺寸（小值）= 成品框
- **成品框**：居中对齐于画布（四边等距内缩），矢量 `<g id="成品框"><rect/></g>`，最顶层
- **元素定位基准**：全部基于**成品框**，不基于画布边缘
- **禁止放大**：元素 PNG 禁止上采样；背景允许等比缩小（Lanczos）
- **背景与成品框解耦**：背景裁切逻辑不感知成品框，先裁背景，再叠矢量成品框

---

#### 5.1.1 背景裁切规则 ✅

> **Viewport = 画布尺寸**（与成品框无关）。  
> 从主底图裁出一个按画布宽高比的矩形，缩放（Lanczos）至画布尺寸，锚点确保罐子落在目标位置。

**内容参考框（视觉定义）**

`5罐子+背景+helix+买点.png`（960×1110mm）定义了必须出现在画布内的内容：罐子（视觉锚点）+ Helix + 买点文案。**它不是裁切尺寸参数，而是理解"什么内容要在画面里"的参照。**

![内容参考框](bg+bg扩展/5罐子+背景+helix+买点.png)

**训练集测量结论（6 张参考稿，330~960mm）**

| 指标 | 值 |
|---|---|
| 内容块（罐左缘→文案右缘）占画布宽 | PoC 定稿 **90%** |
| 两侧边距 | 各约 **5%** |
| 罐心垂直位置 | 画布高度的 **63.8%**（偏下） |

> 📋 **TODO**：90% 为 PoC 固定值，基于 328mm/420mm 画布视觉验证。未来接入更宽格式（580mm+）时需基于实际视觉验证重新校准，考虑动态 range。

**锚点坐标（`bg2000*2000.png`，200 DPI）**

| 参数 | 值 | 说明 |
|---|---|---|
| 罐心在主底图 X | **6568 px**（≈ 834mm） | 15748×15748px 主底图 |
| 罐心在主底图 Y | **9183 px**（≈ 1166mm） | 同上 |
| 罐心目标 X | 画布宽度的 **31.1%** | 罐子偏左，右侧留给 Helix+买点 |
| 罐心目标 Y | 画布高度的 **63.8%** | 罐子略偏下 |

**裁切公式**

```python
crop_w = CONTENT_REF_W_PX / CONTENT_FILL_RATIO  # ≈ 7299 px ≈ 928mm
crop_h = canvas_h_px * crop_w / canvas_w_px      # 按画布宽高比推导

crop_left = CAN_CX - round(crop_w * CAN_TARGET_X)
crop_top  = CAN_CY - round(crop_h * CAN_TARGET_Y)

output = bg.crop(...).resize((canvas_w_px, canvas_h_px), LANCZOS)
output.save(..., dpi=(200, 200))
```

**PoC 两城市裁切区**

| 画布 | 主底图裁切区（px） | 内容块占比 |
|---|---|---|
| 328×470mm 汕头 | 4217~11516 × 2273~13104 | 90% |
| 420×570mm 湛江 | 4217~11516 × 2631~12900 | 90% |

**异常**

| 触发 | 处理 |
|---|---|
| 裁切区 > 主底图任一边 | ⛔ 跳过，记录"主底图尺寸不足" |
| 锚点定位后裁切框超出边界 | ⛔ 跳过，记录"锚点裁切越界" |

---

### 5.2 元素定位规则

> 以下比例均相对于**成品框**的宽（W）和高（H），从 7 张训练集参考图归纳。

| 元素 | 水平位置 | 垂直位置 | 目标宽度 | 锚点 |
|---|---|---|---|---|
| 1 顶部联合 logo | 水平居中 | 距成品框顶边 3–5% H | 55–65% W | 顶边中心 |
| 2 标题文字 | 左边距 2–3% W | 距成品框顶边 10–15% H | 85–95% W | 左上角 |
| 6 原装进口 | 左边距 2–4% W | 中心在 38–45% H 处 | 25–30% W | 左侧中心 |
| 3 脚注 | 左边距 2–3% W | 距成品框底边 4–7% H | 80–90% W | 左下角 |
| 4 右下角 logo | 右边距 2–3% W | 与元素 3 底边对齐 | 15–20% W | 右下角 |

> 📋 **TODO**：元素比例精确数值待更多训练图补充验证（当前基于 7 张）

### 5.3 元素缩放规则

- 目标宽度 = 成品框宽 × 对应百分比（取区间中值）
- 原始宽 > 目标宽：等比缩小，SVG `width` = 目标宽，`height` 按比例自动算
- 原始宽 ≤ 目标宽：触发 `UpscaleError`，整行跳过

### 5.4 图层顺序（底 → 顶）

```
bg.png → 2标题无蒙版 → 6原装进口 → 1顶部联合logo → 3脚注 → 4右下角logo → 成品框
```

### 5.5 特殊说明

- 元素 2 使用**无蒙版**版本（`2标题无蒙版.png`）
- 宽幅格式（960mm+）元素比例规则不变，背景水平展示更多内容

## 6. 输出结构

```
{城市}_{尺寸}.zip
├── {城市}_{尺寸}.svg
└── assets/
    ├── bg.png               ← 裁切+缩放后的背景，画布尺寸，200 DPI
    ├── 1顶部联合 logo.png
    ├── 2标题无蒙版.png
    ├── 3脚注.png
```

SVG 使用相对路径引用（`./assets/xxx.png`），解压即可在 Illustrator 直接打开。  
所有 `<image>` 和 `<rect>` 附加 `data-x-mm / data-y-mm / data-width-mm / data-height-mm` 属性供调试。

**下游交付路径：**
```
收到 ZIP → Illustrator 打开 SVG → （可选调整）→ 转换 CMYK → 导出 PDF/TIFF → 交印刷厂
```

## 7. 异常场景处理

### 场景 A：元素需放大（UpscaleError）✅ 已实现

元素原始像素宽 < 目标显示宽 → 触发 `UpscaleError`，整行跳过，异常清单记录。

> 📋 **待决策**：是否改为"警告+输出半成品"？当前策略：严格跳过（A1）。

### 场景 B：主底图尺寸不足 ✅ 已解决

裁切区 > 主底图边界 → `ValueError`，整行跳过。  
**解决**：已切换至 bg2000（15748×15748px），覆盖所有当前城市。

### 场景 C：锚点裁切越界 ✅ 已实现

锚点定位后裁切框超出主底图边界 → `ValueError`，整行跳过。  
（宽高比极端的格式如 330×558mm 在当前 CONTENT_FILL_RATIO 下可能触发）

### 场景 D：Excel 数据异常 📋 待改进

可视尺寸 > 画面尺寸 → 当前无前置校验，成品框 offset 为负，SVG 视觉异常。  
**建议**：`parse_excel` 阶段加入数据合法性校验，提前报错并跳过。
